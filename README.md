# 🎈 Diversão Premiada - Dia das Crianças

Sistema de premiação para clientes nas lojas participantes e parceiras da Francal Distribuidora. Promoção especial de Dia das Crianças!

## 🚀 Deploy

App disponível em: https://opera-o-hexa.vercel.app

## 🛠️ Rodar Localmente

**Pré-requisitos:** Node.js

1. Instale as dependências:
```bash
npm install
```

2. Configure o `.env` (copie de `.env.example`)

3. Rode o servidor:
```bash
npm run dev
```

## 🎁 Período da Promoção

01/09/2026 até 31/10/2026
